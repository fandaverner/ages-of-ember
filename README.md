# Ages of Ember

*Od ohně ke hvězdám*

Budovatelská strategie v prohlížeči: od jeskyně a ohně v pravěku přes středověk, průmysl a moderní dobu až k vesmírnému výtahu.

**Hrát v prohlížeči:** https://fandaverner.github.io/ages-of-ember/

**Stáhnout pro Windows:** [AgesOfEmber.exe](https://github.com/fandaverner/ages-of-ember/releases/latest/download/AgesOfEmber.exe) (asi 25 MB, nic se neinstaluje). Uložené hry jsou ve složce *Dokumenty\Ages of Ember\Uložené hry*. Kdyby Windows napsal „Systém Windows ochránil počítač“, klikněte na *Další informace → Přesto spustit*.

Ovládání: levé tlačítko myši označuje lidi a stavby, pravé je posílá pracovat. Hra se ukládá sama; v nabídce ☰ Hra → Uložené hry jde uložit pod jménem.

Novou verzi exe sestavíte příkazem `bash desktop/sestavit.sh` (potřebuje Node.js).
