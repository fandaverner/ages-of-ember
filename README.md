# Ages of Ember

*Od ohně ke hvězdám*

Budovatelská strategie v prohlížeči: od jeskyně a ohně v pravěku přes středověk, průmysl a moderní dobu až k vesmírnému výtahu.

**Hrát:** stačí otevřít `index.html` v prohlížeči (nebo stránku na GitHub Pages).

Ovládání: levé tlačítko myši označuje lidi a stavby, pravé je posílá pracovat. Hra se ukládá sama do prohlížeče, v nabídce ☰ Hra jde uložit i do souboru.
